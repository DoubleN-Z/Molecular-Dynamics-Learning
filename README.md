# Molecular Dynamics Learning

Personal notes, codes, and simulation records for learning molecular dynamics (MD) in materials science.

This repository is used to document my learning process, theoretical understanding, coding exercises, and practical simulations.

The focus is on understanding MD from the fundamentals and gradually applying it to materials science problems.

## Learning Goals

- Understand the basic principles of molecular dynamics.
- Learn interatomic potentials and force fields.
- Understand numerical integration algorithms used in MD.
- Implement simple MD simulations using Python.
- Learn to use LAMMPS for atomistic simulations.
- Build and visualize atomic structures.
- Analyze simulation trajectories and physical properties.
- Apply MD to problems in materials science.

## Learning Plan

| Stage | Topics | Progress |
|---|---|---|
| 01. Fundamentals | Atomic structures, Newton's laws, energy, Python basics | Not started |
| 02. MD Theory | Interatomic potentials, Verlet algorithm, ensembles, periodic boundary conditions | Not started |
| 03. Python MD | Basic MD implementation and numerical simulations | Not started |
| 04. LAMMPS | Input scripts, energy minimization, NVE, NVT, NPT | Not started |
| 05. Materials Modeling | Crystal structures, defects, surfaces, grain boundaries | Not started |
| 06. Data Analysis | RDF, MSD, diffusion coefficients, coordination numbers | Not started |
| 07. Research Practice | Simulation projects and literature reproduction | Not started |
